# Contador app

Aplicacion desarrollada para la evaluacion de programacion 3 con flutter.

Esta app fue inspirada en memes y sonidos virales para que cualquiera que la use pase un momento agradable cuando prsione cualquiera de los botones.

Esta Aplicacion consta de 3 partes:

-1 Un contador con 3 botones ,uno de suma,uno de resta y uno de reseteo,esta parte es capas de contar numeros positivos y tambien negativos si descomentamos el if presente en la parte de void quitar,cada uno de los botonos muestra una imagen unica y un sonido particular,

-2 Los datos del desarrollador como su nombre,cedula,correo,direccion,ademas de su foto 

-3 Una parte extra que consta de un juego de Tung tung tung sahur con el que puedes moverte hasta llegar a una meta esquivando los obstaculos,cabe destacar qeu esta parte no entra dentro de la evaluacion y que solo la hice para obtener mas conocimiento con flutter y que se me den sugerencias para mejorar.

Utilice este paquete para poder reproducir los sonidos el cual fue facil de usar y de manejar con solo leer un poco de el.

'package:audioplayers/audioplayers.dart'

Esta app es de facil uso ya que solo con tocar cada una de las opciones del menu puedes entrar a cada una de sus partes y ademas puedes volver al menu haciendo el uso del boton de appbar para volver a atras.Ademas en la parte del contador puedes pasar un rato agradable haciendo sonidos de memes virales ,si te gustan los gatos esta appa es para ti .
